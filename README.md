# Daily:UI - UI 구성 훈련 설정

- GitHub: https://github.com/HSKIM-hub/uiuxprogramming
- 배포: https://hskim-hub.github.io/uiuxprogramming/

## 추가기능

### 입력 경험

- 입력 전에 입력 조건 안내
- 입력 중 글자 수와 조건 충족 여부 표시
- 오류를 고치면 오류 표시가 바로 사라짐
- 색뿐 아니라 문구로도 입력 상태 안내

### 입력 검증과 피드백

- 저장 중 버튼을 잠가 중복 저장 방지
- 저장 후 결과와 다음에 할 일 표시
- 비어 있을 때와 글자 수가 부족할 때 다른 오류 문구 표시

## 확인 방법

### 입력 경험

1. 입력하기 전에 '연습할 화면' 입력칸 아래에 입력 조건 안내와 `0 / 60자`가 보입니다.
2. 두 글자를 입력하면 글자 수가 `2 / 60자`로 바뀌고, 입력칸이 초록색으로 바뀌며, "입력 조건을 충족했습니다."가 나옵니다.
3. 글자를 모두 지우고 '훈련 조건 선택하기'를 클릭하면 입력칸 테두리가 빨간색으로 바뀌고 오류 문구가 나옵니다.
4. 다시 두 글자를 입력하면 오류 문구와 빨간 테두리가 바로 사라집니다.

### 입력 검증과 피드백

1. 1단계에서 입력칸을 비운 채로 '훈련 조건 선택하기'를 클릭하면 "연습할 화면을 입력해 주세요."라는 안내문구가 나옵니다.
2. 한 글자를 입력하면 "연습할 화면은 2자 이상 입력해 주세요."로 바뀝니다.
3. 두 글자 이상 입력하고 3단계까지 이동한 뒤 '설정 완료하기'를 클릭하면 버튼이 '저장하는 중...'으로 바뀌고, 저장 중이라는 문구가 나옵니다.
4. 잠시 기다리면 완료 화면에 저장 결과와 다음에 누를 버튼들이 나타납니다.
