# Daily:UI - UI 구성 훈련 설정

- GitHub: https://github.com/HSKIM-hub/uiuxprogramming
- 배포: https://hskim-hub.github.io/uiuxprogramming/

## 11주차 변경사항

- 지금 보고 있는 메뉴와 고른 필터를 굵은 글씨와 밑줄로 강조
- 지금 보고 있는 메뉴 이름을 브라우저 탭 제목에 표시
- 본문 바로가기 링크 추가
- Esc 키로 열린 모바일 메뉴 닫기
- 필터를 고르면 표시되는 기록 개수 표시
- 고른 상태의 기록이 없으면 전체 보기 버튼으로 전체 기록으로 돌아가기

## 확인 방법

### 메뉴

- 상단 메뉴를 클릭하면 해당 메뉴가 굵은 글씨와 밑줄로 강조되는지
- 브라우저 탭 제목이 `메뉴 이름 | Daily:UI`로 바뀌는지

### 키보드 접근

- 페이지를 연 뒤 Tab 키를 누르면 왼쪽 위에 본문 바로가기 링크가 나타나는지
- 모바일 화면에서 메뉴를 연 뒤 Esc 키를 누르면 메뉴가 닫히고 메뉴 열기 버튼에 포커스가 가는지

### 훈련 기록 필터

- 필터를 선택하면 저장됨 훈련 설정 N개가 표시됩니다. 같은 안내 문구가 나오는지
- 선택한 필터의 기록이 없을 때 전체 보기 버튼을 누르면 전체 필터로 바뀌는지
