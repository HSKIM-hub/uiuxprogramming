## GitHub Repository URL

https://github.com/HSKIM-hub/uiuxprogramming

## Published Website URL

https://hskim-hub.github.io/uiuxprogramming/

## 사용자와 목표

- 사용자 : 하루 한 번 UI 구성을 연습하려는 사람
- 목표 : 오늘 연습할 화면과 훈련 조건을 정하고, 설정한 내용을 확인한다. 미션을 마친 뒤에는 체크리스트로 구성한 화면을 점검한다.

## 사용자의 흐름

1. 훈련 기록 저장에 동의하고 '훈련 시작하기'를 누른다.
2. 오늘 연습할 화면을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 미션 수를 고르고, 필요하면 난이도를 변경한다.
4. 화면, 미션 수, 난이도를 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.
6. 미션을 마쳤다면 'UI 구성 점검하러 가기'를 누른다.
7. 구성한 UI 페이지 링크를 입력하고 체크리스트를 점검한다.
8. 점검 결과를 기록하고 결과 화면에서 확인한다. 필요하면 다시 점검한다.

## 8주차 추가 기능: UI 구성 체크리스트

### 추가한 기능 설명

7주차 훈련 설정을 마친 뒤 훈련 설정 완료에서 'UI 구성 점검하러 가기'버튼을 클릭하여 UI 구성 점검 시작, 미션으로 구성한 UI 페이지 링크를 입력하고 배치·사용성 체크리스트로 스스로 점검해 결과를 확인하는 기능을 추가했다

1. UI 구성 점검 시작

- 행동, 이벤트: 완료 안내에서 'UI 구성 점검하러 가기'를 클릭한다.
- 반응, 다음 상태: UI 구성 체크리스트를 열고 설정한 화면, 미션 수, 난이도를 위쪽에 보여준다.
  링크 입력창을 포커싱한다.

2. 점검 결과 기록

- 행동, 이벤트: 구성한 UI 페이지 링크를 입력하고 점검 항목(배치: 여백·정렬·글자 크기·버튼 크기 / 사용성: 안내 문구·오류 안내·상태 표시·반응형)을 체크한 뒤 '점검 결과 기록하기'를 클릭한다.
- 조건: 링크가 비어 있는가? https://로 시작하는가? 체크한 항목이 있는가? 모든 항목을 충족했는가?
- 반응, 다음 상태: 링크가 비었거나 https://로 시작하지 않으면 고칠 방법을 안내하고 입력창을 포커싱한다.
  올바르면 입력 화면을 닫고 결과 화면에 링크, 충족 항목, 보완할 항목을 보여준다.
  모든 항목을 충족하면 '모든 항목을 충족했어요'를 강조해 보여주고, 아니면 '보완할 항목이 n개 있어요'를 보여준다.
  아무 항목도 체크하지 않으면 충족 항목을 '없음'으로 보여준다.

3. 다시 점검하기

- 행동, 이벤트: 결과 화면에서 '다시 점검하기'를 클릭한다.
- 반응, 다음 상태: 링크와 체크 항목을 초기화하고 입력 화면으로 돌아가 링크 입력창을 포커싱한다.
  위쪽의 화면, 미션 수, 난이도 정보는 유지한다.

### 테스트 결과

1. UI 구성 점검 시작

- 화면 입력, 미션 개수, 난이도 정상 표시

2. 점검 결과 기록

- Input에 입력이 없을 경우 '구성한 UI 페이지 링크를 입력해 주세요.' 안내 후 입력창 포커싱
- 링크가 형식이 맞지 않는 경우 '링크는 https://로 시작해야 합니다. 주소창의 링크를 그대로 붙여 넣어 주세요.' 안내 후 입력창 포커싱
- 결과 화면에 체크 항목에 따라 충족 항목, 보완할 항목 표시 확인
- 모든 항목 체크 시 '모든 항목을 충족했어요' 문구 확인, 일부만 체크 시 '보완할 항목이 n개 있어요' 개수 확인, 아무것도 체크하지 않을 시 충족 항목 '없음' 표시 확인

3. 다시 점검하기

- 입력화면으로 돌아가 Input 포커싱 확인
- 링크 input, 체크리스트 초기화 확인

4. 화면 넓이 768px 이하 테스트

- 훈련 동의 체크리스트 라벨이 세로로 표시되는 문제 수정 확인
- 점검 결과 기록하기, 다시 점검하기 버튼이 화면 폭에 맞게 넓어지는지 확인

## 인터렉션 시나리오

1. 시작과 훈련 기록 저장 안내

- 행동, 이벤트: 훈련 기록 저장 동의 체크박스를 선택하고 '훈련 시작하기'를 클릭한다.
- 조건: 훈련 기록 저장 동의가 선택되었는가?
- 반응, 다음상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 기록 저장 목적을 설명하는 안내 팝업이 열린다.
  팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
  '동의하고 설정 시작하기'를 누르면 연습할 화면 입력 단계를 연다.

2. 연습할 화면 입력

- 행동, 이벤트: 오늘 연습할 화면을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건: 앞뒤 공백을 지운 값이 비어 있는가?
- 반응, 다음상태: 비어 있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
  값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택

- 행동, 이벤트: 미션 수를 바꾸거나 난이도를 설정하고 '내용 확인하기'를 클릭한다.
- 조건: '난이도 변경하기'를 체크했는가?
- 반응, 다음 상태: 체크했을 때만 난이도 선택지(쉬움, 보통, 어려움)를 보여준다. 체크하지 않으면 기본 난이도 '보통'으로 설정한다.

4. 내용 확인

- 행동, 이벤트: 연습할 화면, 미션 수, 난이도를 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건: 수정인가, 완료인가?
- 반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
  완료하면 완료 안내로 이동한다.

5. 완료와 다시 설정

- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 연습할 화면, 미션 수, 난이도, 진행 상태를 초기화하고 화면 입력부터 다시 시작한다.
  UI 구성 점검 입력과 결과도 초기화한다.
  이미 확인한 훈련 기록 저장 동의와 다른 기능은 유지한다.
