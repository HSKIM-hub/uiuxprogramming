# Daily:UI - UI 구성 훈련 설정

## 사용자와 목표

- 사용자 : 하루 한 번 UI 구성을 연습하려는 사람
- 목표 : 오늘 연습할 화면과 훈련 조건을 정하고, 설정한 내용을 확인한다.

## 사용자의 흐름

1. 훈련 기록 저장에 동의하고 '훈련 시작하기'를 누른다.
2. 오늘 연습할 화면을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 미션 수를 고르고, 필요하면 난이도를 변경한다.
4. 화면, 미션 수, 난이도를 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오

1. 시작과 훈련 기록 저장 안내

- 행동, 이벤트: 훈련 기록 저장 동의 체크박스를 선택하고 '훈련 시작하기'를 클릭한다.
- 조건: 훈련 기록 저장 동의가 선택되었는가?
- 반응, 다음상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 기록 저장 목적을 설명하는 안내 팝업이 열린다.
  팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
  '동의하고 설정 시작하기'를 누르면 연습할 화면 입력 단계를 연다.

2. 연습할 화면 입력

- 행동, 이벤트: 오늘 연습할 화면을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건: 앞뒤 공백을 지운 값이 비어 있는가?
- 반응, 다음상태: 비어 있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
  값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택

- 행동, 이벤트: 미션 수를 바꾸거나 난이도를 설정하고 '내용 확인하기'를 클릭한다.
- 조건: '난이도 변경하기'를 체크했는가?
- 반응, 다음 상태: 체크했을 때만 난이도 선택지(쉬움, 보통, 어려움)를 보여준다. 체크하지 않으면 기본 난이도 '보통'으로 설정한다.

4. 내용 확인

- 행동, 이벤트: 연습할 화면, 미션 수, 난이도를 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건: 수정인가, 완료인가?
- 반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
  완료하면 완료 안내로 이동한다.

5. 완료와 다시 설정

- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 연습할 화면, 미션 수, 난이도, 진행 상태를 초기화하고 화면 입력부터 다시 시작한다.
  이미 확인한 훈련 기록 저장 동의와 다른 기능은 유지한다.
