# Daily:UI - UI 구성 훈련 설정

- GitHub: https://github.com/HSKIM-hub/uiuxprogramming
- 배포: https://hskim-hub.github.io/uiuxprogramming/

## 10주차 변경사항

- 지금 보고 있는 메뉴를 강조 표시
- 훈련 기록을 전체, 저장됨, 취소됨으로 나눠 보기
- 고른 상태의 기록이 없으면 안내 문구 표시
- 작은 화면에서는 메뉴 열기 버튼으로 메뉴를 열고 닫기
- 메뉴를 고르면 메뉴가 자동으로 닫힘

## 확인 방법

### 메뉴 이동

- 상단 메뉴를 클릭하면 해당 영역으로 이동하는지

### 훈련 기록 필터

- 전체, 저장됨, 취소됨 버튼에 따라 해당 기록만 보이는지
- 고른 상태의 기록이 없을 때 안내 문구가 나오는지

### 모바일 메뉴

- 600px 이하에서 상단 메뉴가 메뉴 열기 버튼으로 바뀌는지
- 펼친 메뉴에서 메뉴를 고르면 해당 영역으로 이동하고, 고른 메뉴가 강조되는지
