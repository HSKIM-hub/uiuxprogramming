# 5주차 사용자 인터렉션 추가

### 기존 문제점

매주 새 미션 받기에 이메일 입력 후 신청 버튼을 누르면 새로고침이 되어 정상적으로 신청이 완료됐는지 신청 결과를 사용자가 확인할 방법이 없었다.

### 수정한 내용

- 사용자 입력 폼, 버튼에 id를 추가했다.
- 입력 폼에 대한 안내문구를 표시하는 p태그를 추가했다.
- HTML에 script를 추가하여 '#missionRequestButton' 버튼을 눌렀을때 'handleMissionRequest' 함수 실행
- handleMissionRequest: 신청 버튼을 눌렀을때 trim()을 사용하여 공백 필터링 후 입력값을 확인하고 안내 문구와 버튼 상태를 변경한다.
- 입력값이 없는 경우: 안내 문구에 "이메일을 입력한 뒤 신청해주세요." 메세지 표시, 이메일 Input 포커싱
- 입력값이 있는 경우: 'makeMissionRequestMessage' 함수를 이용해 안내문구 변경, 안내문구 클래스 리스트에 "is-success" 추가(메세지 텍스트 초록색으로 표시), 버튼 문구 "신청 완료" 로 변경, 버튼 비활성화(버튼 색상 변경, 커서 not-allowed)
- 이전 피드백 반영사항: style.css 168번 라인 헤더 패딩 지정부분 'padding-top' 을 지정 후 'padding'으로 덮는 문제가 있었습니다. 원래 의도는 'padding-bottom' 이였으나 bottom 누락되어 원래 의도대로 수정했습니다.

### 확인 사항

- 아무것도 입력하지 않고 훈련 소식 신청하기 버튼을 클릭했을때 입력 폼 하단에 '이메일을 입력한 뒤 신청해주세요.' 라는 안내 문구가 표시되고 input에 포커스가 잡히는지 확인
- 공백을 넣은 후 버튼을 클릭하는 경우에도 동일하게 빈값 처리를 하는지 확인
- 이메일 입력 후 버튼을 클릭했을때 버튼 문구가 "신청 완료"로 변경 후 비활성화 처리 되는지 확인, 안내 문구가 "이메일 + 로 신청이 완료되었습니다." 로 표시되는지 확인
